# ProfitDelta Website

Modern responsive landing page for ProfitDelta, built with Next.js, TypeScript, and Tailwind CSS.

## Run Locally

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 3002
```

Open `http://127.0.0.1:3002`.

## Edit Copy

Most page copy is centralized in:

```text
content/siteContent.ts
```

## Build

```bash
npm run build
```
